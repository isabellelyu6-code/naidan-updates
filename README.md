# 奶蛋桌面助手 v2.3

Windows 桌面宠物与轻量桌面助手。正式版本由 GitHub Actions 自动构建并发布；程序启动时会静默检查本仓库的最新 Release。

## 启动

1. 把 ZIP **完整解压**。
2. 双击 `start_pet.bat`。
3. 第一次运行会安装 PySide6，需要联网并稍等片刻。

也可在文件夹中打开 PowerShell，运行：

```powershell
py -m pip install -r requirements.txt
py pet.py
```

## 玩法

- 左键单击：随机表情；按住拖动：移动；快速甩出去：保持同一个无手无脚的奶蛋形象并流畅滚动。
- 右键菜单：动作、表情、天气/时间/日期、番茄钟、正计时、倒计时、提醒、记事、随机决定、截图录屏、快捷入口、迷你蛋模式和语音。
- 天气默认 London，使用 Open-Meteo，无需 API key；可以在菜单中更换城市。
- 笔记、城市、网站和设置保存在同目录 `pet_data.json`。
- 闲置时会向任意方向散步；选择“隐藏成迷你蛋”后会缩到屏幕边缘，双击即可恢复。它取代了原来的安静模式。
- 右键选择“调节大小与长宽”，可以分别调整整体大小、左右宽度和上下高度，并实时预览；设置会自动保存。
- 提醒到点会连续发出三声系统提示音，同时显示弹窗和奶蛋气泡。
- “打开计时面板”集中提供番茄钟、自定义倒计时和正计时；进行中的时间会持续显示在奶蛋头顶，关闭面板也不会停止。
- 气泡会按文字实际大小自动收缩，并随奶蛋的缩放比例贴在头顶；“原地翻滚”只旋转、不位移。
- 截图保存到桌面的 `相册/screenshots`；录屏完成后程序会尝试把系统录屏文件移到同一文件夹。文件夹不存在时会自动创建。
- 倒计时仅在桌宠程序保持运行时有效。

## 一次打开多只（PowerShell）

```powershell
1..3 | ForEach-Object { Start-Process pyw -ArgumentList "pet.py" }
```

如果启动失败，不要关闭黑色窗口，把最后几行截图发给 ChatGPT。

## 生成独立 EXE

双击 `build_exe_windows.bat`，等待自动安装打包工具并完成构建。完成后会出现 `奶蛋` 文件夹；请保留整个文件夹，并双击其中的 `奶蛋.exe`。文件夹版不依赖 Python，也不会显示黑色终端窗口，并且比单文件打包更不容易触发杀毒软件误报。

## 后台与数据

- 奶蛋会显示在 Windows 系统托盘，托盘菜单可以恢复奶蛋、打开计时面板、切换迷你模式和退出。
- 奶蛋运行后也会显示任务栏图标；右键该图标即可“固定到任务栏”。
- 右键可开启或关闭“开机自动启动”。
- 倒计时、提醒和正计时会保存；关闭或重启奶蛋后会按真实截止时间恢复。
- v2.2 默认整体大小为 70%；设置中心可独立调节整体、横向、纵向和透明度。
- “安静奶蛋”会固定在当前位置，但仍可随机做表情、主动说话、显示计时和接收操作。
- 拖动松手后奶蛋会停在当前位置，不再误触发甩动或立即继续行走。
- 设置中心还可选择始终置顶、普通层级或置于窗口下方，锁定位置，开启点击穿透，限制显示器范围，并调节主动说话频率。
- 语音设置可选择 Windows 已安装的系统声音并调节语速；不同电脑可选声音取决于系统语音包。
- v2.3 新增恶魔、十二星座和十二生肖装扮；可以保持原味、固定某套装扮或随机轮换。普通活动与“安静奶蛋”都会继续换装和说专属台词。
- “抱枕休息”使用正面睡帽奶蛋抱着星形枕头；长时间没有操作时也会进入休息状态。
- 身体颜色可以保持默认黄色、从调色盘自选或平滑彩虹轮换；绿色眼睛、嘴巴、腮红和装扮保持原色。
- 语音可选择中文或“日语（气泡仍为中文）”。日语需要先在 Windows 安装日语文本到语音包。
- 快捷入口新增 GO 和 Moodle：优先启动桌面或开始菜单里的同名快捷方式，找不到时打开网页版。

## 自动更新

- 奶蛋启动后会静默检查正式版本；没有新版时不会打扰你。
- 发现新版后会显示版本号和更新说明，由你确认后才下载。
- 下载完成后，奶蛋会自动退出、替换 EXE 并重新打开。
- 下载或替换失败不会删除旧版。
- 右键 `软件更新` 可以立即检查，或关闭/开启自动检查。
- 自动替换只适用于独立的 `奶蛋.exe`；Python 源码版会提示新版，但不会覆盖源码。
